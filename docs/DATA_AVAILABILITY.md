# Data and code availability

The public repository is intended for:

`https://github.com/Ray-315/MCLRP-MFMR`

It contains the MFMR source code, frozen configurations, explicit cross-validation assignments, derived result tables, statistical outputs, archived reconstructed-ablation OOF predictions, integrity/audit files, and plotting/validation scripts.

Upstream CCLE/DepMap, GDSC, CGP/legacy benchmark data, and Cell Model Passports-derived inputs are not redistributed. Users must obtain them under the providers' applicable terms and reconstruct/place the inputs according to `data/README.md`.

Upstream MCLRP source and local translated copies are also not redistributed in this public package; see `THIRD_PARTY.md`.

After the first GitHub release is archived in Zenodo, add the resulting version DOI here and to the manuscript's Data Availability Statement.
