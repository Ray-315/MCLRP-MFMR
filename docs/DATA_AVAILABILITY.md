# Data and code availability

The public code repository is:

`https://github.com/Ray-315/MCLRP-MFMR`

The main Git repository contains the MFMR source code, frozen configurations,
explicit cross-validation assignments, dataset manifests, plotting and
validation scripts, and reproducibility documentation.

The complete frozen derived result archive is distributed separately through
the corresponding GitHub Release and, after archival, Zenodo. This includes
primary final-lock outputs, statistical summaries, protocol-audit files,
reconstructed-ablation outputs, and archived out-of-fold predictions.

Upstream CCLE/DepMap, GDSC, CGP/legacy benchmark data, and Cell Model
Passports-derived inputs are not redistributed. Users must obtain them from the
original providers under the applicable terms and reconstruct/place the inputs
according to `data/README.md`.

Upstream MCLRP source and local translated copies are also not redistributed;
see `THIRD_PARTY.md`.

After the first GitHub release is archived in Zenodo, add the resulting version
DOI here and to the manuscript Data Availability Statement.
